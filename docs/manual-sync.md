# 独立运行与手动同步

客户端以本地数据为准。同步后台不是模型 API、助手目录 API 或启动依赖；保存地址、打开页面、目录过期及未知模型查询都不会连接同步后台。默认地址为空；已有保存地址也不授予自动联网权限。

## 使用

- 设置 → 手动同步：填写 HTTPS 地址或 IP:端口并保存。回环地址可使用 HTTP；非回环必须使用 HTTPS。
- 后台管理员先通过离线 CLI 开通账号，客户端每次操作输入用户名、密码。密码与会话令牌不持久保存。
- **备份到后端**：生成包含会话、附件、设置、助手和 API 凭据的 V3 备份，转换为独立 SQLite 文件，按 1 MiB 分块上传。后台验证分块及全文件 SHA256 后原子提交。
- **从后端覆盖恢复**：下载时固定快照版本，校验分块与全文件，再验证 SQLite/V3 和会话结构。必须确认覆盖；先持久保存本机恢复备份，保存失败不开始覆盖。
- **恢复覆盖前数据（本机）**：不联网地恢复覆盖前的 V3 数据；也可导出恢复 ZIP。
- 清空地址再保存即可断开后台。不会删除本机内容。

“我的搭档”只使用本地数据；创建/编辑支持 category，列表支持分类筛选。默认助手及头像在首次初始化时从打包资源写入本地，已有数据不覆盖，删除后不重新种入。模型目录使用内置快照/本机缓存，自动查询不会访问 models.dev；明确点击模型目录更新仍可能联网。AI 云提供商、用户配置的远程 MCP、联网搜索并不因此离线，本机生成仍需本地推理引擎。

## 存储与安全边界

- 当前 SQLite 是 **V3 便携快照容器**，不是客户端所有运行时存储的统一迁移。知识库文件、所有插件/平台缓存等不在 V3 范围内，不能宣称完整磁盘克隆。
- 默认资源目前通过打包目录初始化；没有用 default.db 替代整个客户端初始化。
- 用户后台保存于 data/users/<username>.db，认证数据库为 data/users.db；所有后台编辑和下载都按登录用户隔离。
- HTTPS 加密传输。后台需要编辑数据，因此落盘是明文，不是端到端加密。快照包含 API 凭据，必须信任后台管理员；建议磁盘加密和严格权限。
- 上限 256 MiB；当前为完整快照分块传输，不是差分同步；最后成功提交覆盖，不合并多设备冲突。
- 本机恢复是逐会话发布，不是所有存储层的单一原子事务。预检、覆盖前备份和本机回退可降低风险，但断电/空间不足仍可能留下部分恢复数据。操作期间应停止生成、关闭其他窗口并避免编辑。
- Web 首次加载需要静态资源服务，尚无 PWA 离线冷启动；桌面资源打包后不依赖应用后台。

账号开通、TLS 白名单、后台启动和协议参见 [后台同步说明](../server/SYNC.md)。
