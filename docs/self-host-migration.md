## 当前架构

- Chatbox UI → 独立 Flask 应用后端，默认 `http://127.0.0.1:4567`。
- 应用后端 → SQLite 助手/配置与本地头像文件，不代理官方、不爬虫、不调用模型。
- Chatbox UI → 用户配置的 Ollama / LM Studio / BYOK / 自定义模型 API。
- **没有**上一轮虚拟域名、fetch/TCP 猴子补丁或全局联网白名单。
  Self-host 指去除官方服务依赖，不等于禁止用户选择远程模型。

在设置 → 高级 → Application API Server 保存自建后端来源。这里只写协议、主机、端口，
不写 `/api` 或模型 `/v1`。没有服务器时会显示连接错误，不回退官方。
切换来源后的新请求用新地址；重新启动 UI 清除其他页面缓存。

## 后端与内容管理

见 `server/README.md`。仅 Flask 一个外部直接依赖，数据库用标准库 `sqlite3`，没有 ORM。
后台采用 CRM 式导航、统计卡片和普通 HTML 表单：助手搜索/语言筛选/分页、增删改、启停及头像管理；
提供商与模型使用字段化 CRUD，应用与 RAG 配置使用输入框、下拉框及复选框，不展示 JSON 编辑器。
有离线导入脚本，可明确指定旧助手 JSON 和本地素材目录；默认不导入第三方内容。

默认只面向本机，Host/回环校验、CSRF、无 CDN；不支持直接公网暴露。
跨平台路径使用 pathlib，Windows 不需要 Ruby/MSYS。生产远程部署需另外配置认证、TLS 与 WSGI。
